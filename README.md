# CMRB — Dossier client de la baseline

## Ordre de lecture recommandé

1. Lire le [dossier global avant contrat](CMRB_DOSSIER_GLOBAL_AVANT_CONTRAT.md), document autonome soumis à approbation globale.
2. Utiliser le [document détaillé des workflows](CMRB_WORKFLOWS_FOR_VALIDATION.md) et le [dictionnaire de données](CMRB_DATA_DICTIONARY_FOR_VALIDATION.md) comme annexes de travail.
3. Lire les 35 décisions clôturées en fin du document des workflows pour la traçabilité historique.

## Approbation globale et changements

L’approbation porte sur le dossier global. Une correction cite WF, ENT/champ ou Q, précise le changement, son motif, son décideur et sa date, puis est instruite comme une demande de changement. Le [registre canonique](OPEN_QUESTIONS_AND_DECISIONS.md) conserve les décisions de baseline.
